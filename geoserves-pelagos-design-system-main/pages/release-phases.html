Stability Lifecycle

Phase Overview
Components progress from experimental → alpha → beta → stable. Only stable components are recommended for production use.

Experimental

Early proof-of-concept components available for design exploration and prototyping only. APIs are highly unstable and may change or be removed without notice. Not for production use.

Experimental

Alpha

Components under active development. The core API shape is emerging but breaking changes are expected between minor versions. Use in non-critical product surfaces only, with the understanding that upgrades will require code changes.

Alpha

Beta

Components that are feature-complete and undergoing stability hardening. The public API is unlikely to change but may see small adjustments based on feedback. Recommended for use in production with awareness of possible minor changes.

Beta

Stable

Production-ready components with a locked public API. Breaking changes will only occur in major version releases with a migration guide. Full accessibility, documentation, and browser support is guaranteed.

Stable

Deprecated

Components that are scheduled for removal in a future major release. A replacement component or migration path is always documented. Deprecated components continue to receive security patches but no new features.

Deprecated
