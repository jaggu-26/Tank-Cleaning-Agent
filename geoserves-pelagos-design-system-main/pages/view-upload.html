Upload

The Upload component provides a dashed drop zone for file input via drag-and-drop or click-to-browse. The border uses Grey/400 in default state transitioning to Primary/Marine on hover/drag. Folder illustrations from the design system asset library (img-folder-closed / img-folder-opened) signal the state change.

Variants

Two size variants for different layout contexts. Large is the primary drop zone. Small fits toolbar, sidebar, or inline form rows. Both use Grey/400 dashed border and the design system folder illustrations.

When to Use
  • File attachment flows — document uploads, SoF attachments, charter party drafts. Pair with a file list below the zone to show progress and allow removal.
  • Drag-and-drop context — when users are expected to have files open in their OS. The folder illustration (img-folder-opened) reinforces the drop affordance on hover.
  • Small for inline contexts — the small variant fits form rows, sidebars, or table cells where vertical space is limited.
Visual Behaviour
  • Default border — 1px dashed Grey/400 (--prim-grey-400, #64748B). This is specified in Figma as the "Inside stroke, Weight 1, Grey/400" rule.
  • Hover / drag-over — border transitions to Primary/Marine, background to Blue/10 (#EEF6FF). The folder illustration swaps from img-folder-closed to img-folder-opened.
  • "Browse" is a link-button — it uses class="gs-upload__link-btn" which applies underline, marine color, and a hover state, while being a proper <button type="button"> for keyboard and accessibility.
  • File list — after selection/drop, render gs-file-list rows below the zone. Each row has the file icon, name, size, and a progress bar animating to 100%.
Accessibility
  • The drop zone has role="button" and tabindex="0" so keyboard users can focus it and activate with Enter/Space.
  • The hidden <input type="file"> is the actual browser mechanism. It fills the zone via position:absolute; inset:0; opacity:0.
  • "Browse" is a <button type="button"> (not a <span> or <a>) so it's natively keyboard-focusable and reads as a button to screen readers.
  • Upload progress should be announced via a live region or by updating aria-valuenow on each file's progress bar.
