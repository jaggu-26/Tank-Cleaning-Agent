Dropdown

The Dropdown is built on the Text Field (gs-tf-box) as its trigger base. When opened, the field transforms into an inline search bar — the trailing chevron swaps to a magnifier icon and the input becomes live-filterable. Three selection modes cover every use case.

Trigger States

The trigger is identical to a Text Field in closed state. When opened it becomes a search input — the chevron icon is replaced by a magnifier and typing filters the list in real time.

Overview

The Dropdown component wraps the Text Field () as its trigger base and adds a searchable panel. It is fully controlled — pass value and onChange. When multiple is set, selections render as inline chips () inside the trigger and wrap at max-height 136px.

In Angular or plain HTML, use the gs-dd CSS class family directly. All behaviour is wired via gsDdToggle, gsDdSelect, gsDdFilter etc. defined in script.js. Add gs-dd--multi for multi-select chip behaviour.

Full HTML Structure

The React component generates this markup. You can also use the classes directly as shown in the Angular tab.

Use gsDdToggle(id), gsDdSelect(id, label), gsDdFilter(id, query) from script.js. Add gs-dd--multi for multi-select.

HTML — single select
<!-- Single select. Add .gs-dd--multi + .gs-dd__chips-wrap for multi -->
<div class="gs-dd" id="my-dd">

  <!-- Label (Caption 1 SB — 12px, --dd-label-color) -->
  <div class="gs-dd__label">Port</div>

  <!-- Trigger: extends gs-tf-box base from Text Fields -->
  <div class="gs-dd__trigger" tabindex="0"
       onclick="gsDdToggle('my-dd')"
       aria-haspopup="listbox" aria-expanded="false">
    <div class="gs-dd__value-area">
      <!-- Closed: display value / placeholder -->
      <span class="gs-dd__display is-placeholder">Select port…</span>
      <!-- Open: search input (--dd-border-open focus ring) -->
      <input class="gs-dd__search" placeholder="Search ports…"
             oninput="gsDdFilter('my-dd',this.value)"/>
    </div>
    <!-- Clear btn — visible via .has-value -->
    <button class="gs-dd__clear"
            onclick="event.stopPropagation();gsDdClear('my-dd')"
            aria-label="Clear">×</button>
    <!-- Chevron (closed) / Magnifier (open) -->
    <span class="gs-dd__chevron">↓</span>
    <span class="gs-dd__mag">🔍</span>
  </div>

  <!-- Panel: shadow-md, 4px radius, max-height 320px -->
  <div class="gs-dd__panel" role="listbox">
    <div class="gs-dd__list">
      <!-- 40px item, Blue/10 hover, selected = .is-selected -->
      <div class="gs-dd__item" role="option"
           onclick="gsDdSelect('my-dd','Singapore, SGP')">
        <span class="gs-dd__item-text">Singapore, SGP</span>
        <span class="gs-dd__item-check" aria-hidden="true">✓</span>
      </div>
      <div class="gs-dd__empty" style="display:none">No results</div>
    </div>
  </div>
</div>

Backend Integration

Use gsDdSetOptions or gsDdFetch to decouple the component from hardcoded HTML. All option fields except value and label are optional — add only what your data provides.

gsDdSetOptions — populate from any JS array
tsx
// Option shape — every field except value + label is optional
const options: DropdownOption[] = [
  { value: 'list-1', label: 'List Item 1' },
  { value: 'list-2', label: 'List Item 2', sub:  'Sub-label' },
  { value: 'list-3', label: 'List Item 3', right: '<span class="gs-cs gs-cs--blue">Badge</span>' },
  { value: 'list-4', label: 'List Item 4', group: 'Section A' },
  { value: 'list-5', label: 'List Item 5', disabled: true },
];

// Link to backend — map your API response to this shape:
const mapped = apiResponse.map(item => ({
  value: item.id,
  label: item.name,
  sub:   item.description,
  right: item.status ? `<span class="gs-cs gs-cs--green">${item.status}</span>` : undefined,
}));

// Populate the dropdown — replaces all existing items
gsDdSetOptions('my-dd', mapped);
javascript
// Works in any framework or vanilla JS
gsDdSetOptions('my-dd', [
  { value: 'list-1', label: 'List Item 1' },
  { value: 'list-2', label: 'List Item 2', sub: 'Sub-label' },
]);

// Re-call any time your data changes — items are fully replaced
gsDdFetch — load directly from a REST endpoint
tsx
// 1. Opens dropdown with loading skeleton automatically
// 2. Fetches the URL, parses JSON
// 3. Calls your mapper on each item → DropdownOption
// 4. Populates the list (or shows error state on failure)

gsDdFetch(
  'vessel-dropdown',
  '/api/vessels?limit=50',
  vessel => ({
    value: vessel.imo,
    label: vessel.name,
    sub:   vessel.flag + ' · ' + vessel.type,
    right: vessel.active
      ? '<span class="gs-cs gs-cs--green">Active</span>'
      : '<span class="gs-cs gs-cs--grey">Inactive</span>',
  })
);

// Supported envelope shapes (auto-detected):
// { results: [...] }  { items: [...] }  { data: [...] }  [...] (root array)
javascript
gsDdFetch(
  'vessel-dropdown',
  '/api/vessels',
  function(v) {
    return { value: v.imo, label: v.name, sub: v.flag };
  }
);

// Error state: shown in the empty-state row if fetch fails

When to Use
  • 5+ options — use Dropdown when there are 5 or more choices. For 2–4 use Radio group or Segmented Button instead.
  • Search needed — the built-in search (chevron → magnifier on open) activates automatically for any length list.
  • Multi-select — use the multiple prop when users need multiple values (fuel types, ports). Always shows an Apply footer.
Open → Search behaviour
  • Opening — clicking the trigger opens the panel. The chevron rotates 180° and is replaced by a magnifier. Focus moves to the hidden search input.
  • Filtering — typing hides non-matching items in real time (case-insensitive). An empty state appears when zero items match.
  • Selection — single: clicking an item closes the panel. Multi: items toggle checkboxes; panel stays open until Apply is clicked.
  • Closing — Esc, clicking the backdrop, or Tab blur closes the panel and restores the chevron.
Accessibility
  • Trigger is tabindex="0"; responds to Enter/Space to open.
  • Focus moves to the search input on open for immediate keyboard filtering.
  • Arrow keys navigate visible, non-disabled items.
  • Clear button has aria-label="Clear selection".
  • Trigger reports aria-expanded state.
