Text Fields

Text fields collect user input in a structured, accessible container. The system provides two sizes (Large / Small), eight states, and multiple composition patterns - all wired to a 3-tier CSS token system so styling changes cascade automatically.

Sizes

Two height options scale with your interface density. Large (40 px) is the default for forms; Small (32 px) suits compact toolbars, inline filters, and data tables.

theme/gs-theme.js

JavaScript · Geoserve Theme 
/**
 * Geoserve UI theme config - injected via ConfigProvider.
 * CSS custom properties are read at runtime so any :root update
 * cascades here automatically - no hard-coded hex values.
 *
 * Token chain example:
 *   colorPrimary  ←  --prim-marine  ←  :root { --prim-marine: #1852FE }
 */
const cssVar = (name) =>
  getComputedStyle(document.documentElement).getPropertyValue(name).trim();

const gsTheme = {
  token: {
    colorPrimary:    cssVar('--prim-marine'),       // → #1852FE
    colorError:      cssVar('--prim-red-500'),      // → #DC2625
    borderRadius:    4,                             // --prim-radius-sm
    fontFamily:      cssVar('--prim-font-primary'),  // Gilroy stack
    fontSize:        14,                            // --prim-font-size-md
    controlHeight:   40,                            // --tf-height-lg
    controlHeightSM: 32,                            // --tf-height-sm
  },
  components: {
    Input: {
      paddingInline:     12,                           // --tf-padding-x
      colorBgContainer:  cssVar('--color-surface-default'), // --tf-bg → #fff
      colorBorder:       cssVar('--prim-grey-200'),        // --tf-border-default → #cbd5e1
      colorPrimaryHover: cssVar('--prim-grey-300'),        // --tf-border-hover → #94a3b8
      hoverBorderColor:  cssVar('--prim-grey-300'),        // matches hover state
    },
  },
};

export default gsTheme;

TextField/TextField.jsx

JSX · Geoserve TextField Component 
import { Input } from 'antd';          // underlying library
import { ConfigProvider } from 'antd';
import gsTheme from '../../theme/gs-theme';
import './TextField.scss';

const { TextArea } = Input;
const BaseInput = Input;  // alias - keeps GS naming in JSX

// Maps GS size shorthand to internal size prop values
const SIZE_MAP = {
  lg: 'large',
  sm: 'small',
};

// Maps GS status to internal antd status prop ('error' | undefined)
const STATUS_MAP = {
  default: undefined,
  error:   'error',
  success: undefined,  // success handled via className → SCSS token
};

/**
 * @param {object}  props
 * @param {'lg'|'sm'}                        [props.size='lg']
 * @param {'default'|'error'|'success'}      [props.status='default']
 * @param {string}                           [props.label]
 * @param {boolean}                          [props.required=false]
 * @param {string}                           [props.helpText]
 * @param {React.ReactNode}                  [props.prefix]
 * @param {React.ReactNode}                  [props.suffix]
 * @param {React.ReactNode}                  [props.addonBefore]
 * @param {React.ReactNode}                  [props.addonAfter]
 * @param {boolean}                          [props.multiline=false]
 * @param {number}                           [props.rows=3]
 */
const TextField = ({
  size      = 'lg',
  status    = 'default',
  label,
  required  = false,
  helpText,
  prefix,
  suffix,
  addonBefore,
  addonAfter,
  multiline = false,
  rows      = 3,
  className = '',
  ...props
}) => {
  const statusClass = status === 'error'   ? 'status-error'
    : status === 'success' ? 'status-success' : '';

  const helpClass = status === 'error'   ? 'gs-tf-help is-error'
    : status === 'success' ? 'gs-tf-help is-success' : 'gs-tf-help';

  const cls = ['gs-tf', statusClass, className].filter(Boolean).join(' ');

  return (
    <ConfigProvider theme={gsTheme}>
      <div className="gs-tf-wrapper">

        {label && (
          <div className="gs-tf-label-row">
            <span className="gs-tf-label">{label}</span>
            {required && <span className="gs-tf-required">*</span>}
          </div>
        )}

        {multiline ? (
          <TextArea
            className={cls}
            rows={rows}
            status={STATUS_MAP[status]}
            {...props}
          />
        ) : (
          <BaseInput
            size={SIZE_MAP[size]}
            status={STATUS_MAP[status]}
            className={cls}
            prefix={prefix}
            suffix={suffix}
            addonBefore={addonBefore}
            addonAfter={addonAfter}
            {...props}
          />
        )}

        {helpText && (
          <div className={helpClass}>{helpText}</div>
        )}

      </div>
    </ConfigProvider>
  );
};

export default TextField;

textfield/textfield.component.ts

TypeScript · Angular
import {
  Component, Input, Output, EventEmitter, forwardRef
} from '@angular/core';
import { CommonModule } from '@angular/common';
import {
  ControlValueAccessor, NG_VALUE_ACCESSOR, ReactiveFormsModule
} from '@angular/forms';

@Component({
  selector: 'gs-textfield',
  standalone: true,
  imports: [CommonModule, ReactiveFormsModule],
  templateUrl: './textfield.component.html',
  styleUrls: ['./textfield.component.scss'],
  providers: [{
    provide: NG_VALUE_ACCESSOR,
    useExisting: forwardRef(() => TextfieldComponent),
    multi: true,
  }],
})
export class TextfieldComponent implements ControlValueAccessor {
  @Input() label = '';
  @Input() placeholder = '';
  @Input() hint = '';
  @Input() error = '';
  @Input() prefix = '';
  @Input() suffix = '';
  @Input() disabled = false;
  @Input() type = 'text';
  @Output() valueChange = new EventEmitter<string>();

  value = '';
  isFocused = false;

  onChange = (_: string) => {};
  onTouched = () => {};

  writeValue(val: string): void             { this.value = val ?? ''; }
  registerOnChange(fn: (_: string) => void): void { this.onChange = fn; }
  registerOnTouched(fn: () => void): void         { this.onTouched = fn; }
  setDisabledState(d: boolean): void              { this.disabled = d; }

  handleInput(event: Event): void {
    const val = (event.target as HTMLInputElement).value;
    this.value = val;
    this.onChange(val);
    this.valueChange.emit(val);
  }
}

TypeScript · Component
import { Component } from '@angular/core';
import { FormBuilder, Validators, ReactiveFormsModule } from '@angular/forms';
import { TextfieldModule } from './shared/textfield/textfield.module';

@Component({
  standalone: true,
  imports: [TextfieldModule, ReactiveFormsModule],
  template: `
    <form [formGroup]="form" (ngSubmit)="onSubmit()">
      <gs-textfield
        label="Vessel Name"
        formControlName="vesselName"
        [error]="nameError"
      ></gs-textfield>
      <gs-textfield
        label="IMO Number"
        formControlName="imoNumber"
        hint="7-digit IMO identifier"
        [error]="imoError"
      ></gs-textfield>
    </form>
  `,
})
export class VesselFormComponent {
  form = this.fb.group({
    vesselName: ['', Validators.required],
    imoNumber:  ['', [Validators.required, Validators.pattern(/^\d{7}$/)]],
  });

  get nameError() {
    const c = this.form.get('vesselName');
    return c?.invalid && c?.touched ? 'Vessel name is required' : '';
  }
  get imoError() {
    const c = this.form.get('imoNumber');
    if (!c?.invalid || !c?.touched) return '';
    return c.errors?.['required'] ? 'IMO number is required' : 'Must be 7 digits';
  }

  constructor(private fb: FormBuilder) {}
  onSubmit() { if (this.form.valid) console.log(this.form.value); }
}

Dos & Don'ts

Do

  • Always include a visible label above the field - never rely solely on placeholder text
  • Use error state with a descriptive helpText message immediately after form submission or real-time validation
  • Mark required fields with the asterisk required prop; mention optionality only for optional fields
  • Use Large size as the default; switch to Small only when space is genuinely constrained
  • Use type="password" with an eye-toggle suffix for password fields
  • Provide auto-complete hints (autoComplete="email") to aid browser and password-manager support

Don't

  • Don't use placeholder text as a substitute for a label - it disappears on focus and fails contrast requirements
  • Don't show error state on an untouched field before the user has had a chance to interact
  • Don't mix Large and Small inputs in the same horizontal row - heights must be consistent
  • Don't truncate or wrap the label - use concise, single-line label copy
  • Don't use a textarea when a single line will do - reserve multiline for genuinely open-ended input
  • Don't disable a field without providing context; use a helpText or tooltip explaining why

Accessibility

WCAG 2.1 AA Checklist

Every input must have an associated <label> element. Use the label prop - it renders a visible label. Never use aria-label as a replacement for visible text unless the field is icon-only.
Error messages rendered via helpText should be linked to the input with aria-describedby so screen readers announce the message on focus. Add aria-invalid="true" when status="error".
Focus rings use box-shadow only - no outline-offset gap between the border and ring. The 3px glow passes WCAG 2.4.11 (Focus Appearance) at all sizes.
All text colours meet WCAG AA contrast: label (#334154 on #fff) 10.2:1 · placeholder (#64748b on #fff) 5.9:1 · error message (#b91c1b on #fff) 6.3:1 · success message (#147638 on #fff) 7.1:1.
Don't rely on colour alone to communicate error state - always pair the red border with an explicit helpText error message.
Minimum touch target for the Large size is 40×40px. For Small (32px height), ensure the surrounding tap area is padded to at least 40px on touch devices.
