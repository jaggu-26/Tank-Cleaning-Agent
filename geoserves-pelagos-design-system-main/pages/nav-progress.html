Progress Bar

A Progress Bar communicates the completion status of a task or process. Use it whenever you can express progress as a percentage — file uploads, form steps, onboarding flows, or data processing jobs.

When to Use
  • Measurable progress — whenever you can express completion as 0–100%: file uploads, multi-step forms, data processing, onboarding flows.
  • Background operations — tasks that run while the user continues working. Place below the relevant panel or in a persistent footer row.
  • Upload feedback — pair with the Upload component. Each file in the list shows its own progress bar row.
When Not to Use
  • Unknown duration — use a Spinner with the indeterminate prop, or this component's own indeterminate mode.
  • Named steps — for multi-step wizards with labelled checkpoints, use the Stepper component.
  • Micro-interactions (<500ms) — instant actions need only a success Toast, not a progress bar.
Accessibility
  • Set role="progressbar" on the container. Update aria-valuenow as progress changes for live screen-reader announcements.
  • For indeterminate bars, omit aria-valuenow, add aria-busy="true", and provide an aria-label describing what is loading.
  • Pair with a visible or visually-hidden label — "Uploading vessel documents" is more useful than "Loading".
  • prefers-reduced-motion pauses the indeterminate animation automatically.
