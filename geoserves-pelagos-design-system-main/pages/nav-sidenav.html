Side Navigation

Overview

The Side Navigation is a single sidebar element that expands its width from 56px → 260px. The collapsed icon rail is always visible; clicking ☰ expands it with labels, logo, and a backdrop overlay. GPU compositing (will-change: width; transform: translateZ(0)) minimises transition artefacts. Clicking × or the backdrop collapses it.

Anatomy — Two States

A single sidebar element with three zones. Width expands in-place. Labels are always in the DOM but hidden via max-width:0; opacity:0 — no layout shift, no content shift.

Collapsed (56px — always visible)
  • Hamburger ☰ at top
  • Icon-only nav items centred
  • Footer icons stacked vertically
  • No backdrop
Expanded (260px — overlay)
  • GeoServes logo + × close
  • Icon + label items, accordion
  • Footer icons horizontal row
  • Dark backdrop over content

When to Use
  • Multi-section apps (4+ routes) — Collapsed rail provides quick icon access; expanding reveals labels.
  • Space-constrained dashboards — 56px collapsed state maximises content area.
  • Cross-product shell — Change the logo and nav items to deploy across all GeoServes products.
Best Practices
  • Icons must be self-explanatory — In collapsed state only icons are visible. Add title attributes.
  • Persist expanded state — Store in localStorage so the state survives navigation.
  • Close on backdrop + Escape — Both dismiss paths are required for accessibility.
