Buttons

Buttons initiate actions and communicate state. The system provides four button families - each with three visual variants (Primary, Secondary, Tertiary) and three sizes (Large, Medium, Small). Use the right family and variant to convey action priority clearly.

Default

The default family uses brand blue to signal positive, affirmative actions - submitting forms, confirming decisions, or navigating forward. Three variants let you layer visual hierarchy within the same screen.

Loading State

Add .gs-btn--loading to any button to replace the left content with an animated spinner and disable interaction. The spinner colour is automatically derived from the button's colour family — white on dark backgrounds, brand blue on light ones. Always pair with disabled or aria-disabled="true".

Design Tokens

Button styling flows through a 3-tier token system. Component tokens (--btn-*) reference semantic tokens, which reference primitive values - so overriding a single semantic token cascades through all components that use it.

Quick Access

The Button component is a Pelagos primitive. The React implementation is a thin wrapper on top of Ant Design's Button — all interactive behaviours (loading spinner, wave-ripple, keyboard activation, link rendering) are delegated to AntD. Pelagos design tokens are injected per-variant via a scoped ConfigProvider in buttonTheme.js so they never leak into the global theme. Global tokens are shared across all components via pelagosTheme.js; mount PelagosProvider once at your app root to apply them system-wide, or rely on each component’s own scoped provider — either approach works independently. The Angular implementation is a standalone CSS component that uses the same Pelagos token chain via _variables.scss.

/**
 * buttonTheme.js — scoped ConfigProvider theme per variant.
 *
 * Maps Pelagos design tokens (foundations/) to AntD v5 Button component
 * tokens. Global tokens (colour, typography, radius) and shared control
 * heights are imported from pelagosTheme.js so they stay in sync with
 * every other Pelagos component wrapper.
 *
 * Token chain:  colorPrimary  ←  --prim-marine  ←  #1852FE
 */

import { globalTokens, globalComponentTokens } from '../../../pelagosTheme.js';

// ── Button-specific component tokens only ─────────────────────────────────
//    Heights come from globalComponentTokens (shared with Input, Select, …)
//    AntD defaults:  SM=24 / middle=32 / LG=40  →  Pelagos: 32 / 40 / 48
const baseButtonTokens = {
  ...globalComponentTokens,              // controlHeight / LG / SM
  paddingInline:     16,  paddingInlineLG:    24,  paddingInlineSM:    12,
  contentFontSize:   14,  contentFontSizeLG:  16,  contentFontSizeSM:  12,
  fontWeight:        600,
  primaryShadow: 'none', defaultShadow: 'none', dangerShadow: 'none',
};

export const variantThemes = {
  // primary — colorPrimary drives bg + border + focus ring
  primary:   { token: globalTokens, components: { Button: baseButtonTokens } },

  // secondary — tinted brand bg, brand text + border (default type)
  secondary: { token: globalTokens, components: { Button: { ...baseButtonTokens,
    defaultBg:               '#eef6ff', // --color-brand-subtle
    defaultBorderColor:      '#bedbfe', // --color-brand-border
    defaultColor:            '#1852FE', // --color-brand
    defaultHoverBg:          '#dde7ff', defaultHoverBorderColor: '#bedbfe',
    defaultActiveBg:         '#bedbfe', defaultActiveColor:      '#1242d4',
  }}},

  // tertiary — transparent bg, brand text (text type)
  // colorText scoped here to brand blue — safe, wraps only this button
  tertiary: {
    token: { ...globalTokens, colorText: '#1852FE' },
    components: { Button: { ...baseButtonTokens, textHoverBg: '#eef6ff' } },
  },

  // danger — colorError drives bg + border + focus ring (primary + danger)
  danger: { token: globalTokens, components: { Button: baseButtonTokens } },

  // danger-secondary — subtle red bg (default + danger)
  // colorBgContainer sets initial bg; colorErrorBg/BgHover set hover/active
  'danger-secondary': {
    token: { ...globalTokens,
      colorBgContainer:  '#fef1f2', // --color-danger-subtle (initial bg)
      colorErrorBg:      '#fde2e2', // --prim-red-50         (hover bg)
      colorErrorBgHover: '#fecaca', // --prim-red-100        (active bg)
      colorErrorBorder:  '#fecaca', // --prim-red-100        (initial border)
    },
    components: { Button: baseButtonTokens },
  },

  // neutral — grey palette, no brand tint (default type)
  neutral: { token: globalTokens, components: { Button: { ...baseButtonTokens,
    defaultBg:               '#ffffff', defaultBorderColor:      '#e2e8f0',
    defaultColor:            '#475569', // --prim-grey-500
    defaultHoverBg:          '#f1f5f9', defaultHoverBorderColor: '#e2e8f0',
    defaultActiveBg:         '#e2e8f0', defaultActiveColor:      '#334154',
  }}},

  // link — colorLink / colorLinkHover / colorLinkActive drive text colour
  link: { token: globalTokens, components: { Button: baseButtonTokens } },
};

/** Returns the scoped ConfigProvider theme for a given Pelagos variant. */
export const getButtonTheme = (variant) =>
  variantThemes[variant] ?? variantThemes.primary;

import React from 'react';
import { Button as AntButton, ConfigProvider } from 'antd';
import { getButtonTheme } from './buttonTheme';
import './Button.scss';

// ── Variant → AntD type + danger ─────────────────────────────────────────
// Extending variants requires only a new entry here — no other code changes.
const VARIANT_MAP = {
  primary:            { type: 'primary', danger: false },
  secondary:          { type: 'default', danger: false },
  tertiary:           { type: 'text',    danger: false },
  danger:             { type: 'primary', danger: true  },
  'danger-secondary': { type: 'default', danger: true  },
  neutral:            { type: 'default', danger: false },
  link:               { type: 'link',    danger: false },
};

// ── Pelagos size → AntD size ──────────────────────────────────────────────
const SIZE_MAP = { sm: 'small', md: 'middle', lg: 'large' };

// ── Component ─────────────────────────────────────────────────────────────
// React.forwardRef preserves ref compatibility: form libraries (react-hook-form,
// Formik), focus management, and any existing ref usage in the consuming app.
export const Button = React.forwardRef(function Button(
  {
    // ── Pelagos-specific props ──────────────────────────────────────────
    variant   = 'primary',
    size      = 'md',
    iconLeft,
    iconRight,
    fullWidth = false,
    type      = 'button',   // HTML button type → AntD htmlType

    // ── AntD v5.13+ interception (not forwarded) ───────────────────────
    color,              // AntD v5.13+ color prop — use variant instead

    // ── AntD props ─────────────────────────────────────────────────────
    disabled  = false,
    loading   = false,  // boolean | { delay: number }
    onClick,
    children,
    className,
    ...rest             // href, target, shape, ghost, classNames, styles…
  },
  ref,
) {
  const { type: antType, danger } = VARIANT_MAP[variant] ?? VARIANT_MAP.primary;
  const antSize                   = SIZE_MAP[size]        ?? 'middle';

  // Single icon → AntD icon + iconPosition (gap + alignment handled by AntD).
  // Both icons  → manual spans; AntD still renders the button shell.
  const hasBothIcons = Boolean(iconLeft && iconRight);
  let icon, iconPosition;
  if (!hasBothIcons) {
    if (iconLeft)  { icon = iconLeft;  iconPosition = 'start'; }
    if (iconRight) { icon = iconRight; iconPosition = 'end';   }
  }

  return (
    <ConfigProvider theme={getButtonTheme(variant)}>
      <AntButton
        ref={ref}
        type={antType}
        danger={danger}
        size={antSize}
        disabled={disabled}
        loading={loading}
        block={fullWidth}
        icon={icon}
        iconPosition={iconPosition}
        htmlType={type}
        onClick={onClick}
        className={className}
        data-variant={variant}
        {...rest}
      >
        {hasBothIcons ? (
          <>
            <span className="btn__icon--left">{iconLeft}</span>
            {children}
            <span className="btn__icon--right">{iconRight}</span>
          </>
        ) : children}
      </AntButton>
    </ConfigProvider>
  );
});

Button.displayName = 'PelagosButton';
export default Button;

import {
  Component, Input, Output, EventEmitter, OnChanges, SimpleChanges,
} from '@angular/core';
import { getButtonTheme } from './buttonTheme';

// ── Variant → ng-zorro nzType + nzDanger ─────────────────────────────────
const VARIANT_MAP: Record<string, { nzType: string; nzDanger: boolean }> = {
  primary:            { nzType: 'primary', nzDanger: false },
  secondary:          { nzType: 'default', nzDanger: false },
  tertiary:           { nzType: 'text',    nzDanger: false },
  danger:             { nzType: 'primary', nzDanger: true  },
  'danger-secondary': { nzType: 'default', nzDanger: true  },
  neutral:            { nzType: 'default', nzDanger: false },
  link:               { nzType: 'link',    nzDanger: false },
};

const SIZE_MAP: Record<string, string> = { sm: 'small', md: 'default', lg: 'large' };

@Component({
  selector: 'gs-button',
  templateUrl: './Button.component.html',
  host: { class: 'gs-button-host' },
})
export class ButtonComponent implements OnChanges {
  // ── Pelagos props ──────────────────────────────────────────────────────
  @Input() variant = 'primary';
  @Input() size: 'sm' | 'md' | 'lg' = 'md';
  @Input() fullWidth = false;

  // ── ng-zorro props (forwarded directly) ───────────────────────────────
  @Input() loading = false;
  @Input() disabled = false;
  @Input() ghost = false;
  @Input() shape: 'default' | 'circle' | 'round' = 'default';
  @Input() type: 'button' | 'submit' | 'reset' = 'button';
  @Input() href?: string;
  @Input() target?: string;
  @Output() clicked = new EventEmitter<MouseEvent>();

  // ── Derived ng-zorro bindings (resolved on change) ────────────────────
  nzType = 'primary';
  nzDanger = false;
  nzSize = 'default';

  ngOnChanges(changes: SimpleChanges): void {
    if (changes['variant']) {
      const m = VARIANT_MAP[this.variant] ?? VARIANT_MAP['primary'];
      this.nzType   = m.nzType;
      this.nzDanger = m.nzDanger;
    }
    if (changes['size']) {
      this.nzSize = SIZE_MAP[this.size] ?? 'default';
    }
  }

  handleClick(event: MouseEvent): void { this.clicked.emit(event); }
}

Quick Access

Choosing the right button communicates the importance of an action and guides users toward the correct decision. Follow these guidelines to ensure consistency across the product.

When to Use Each Family

Default

Positive, affirmative actions that move the user forward. The most visually prominent button - use once per view for the highest-priority action.

Save Submit Create Confirm
Danger

Destructive actions that are difficult or impossible to reverse. Always confirm before executing the Primary danger variant.

Delete Remove Discard Terminate
Neutral

Low-emphasis utility actions that carry no affirmative or destructive meaning. Always paired alongside a Primary or Danger button.

Cancel Go back Close Skip
Link

Supplementary or in-line actions with the lowest visual weight. Use within body copy or dense UIs to avoid adding visual clutter.

View details Learn more Undo

Variant Priority Hierarchy

① Primary
Maximum visual weight. Reserve for the single most important action per view.
② Secondary
Medium weight. Supports the Primary action or offers a meaningful alternative path.
③ Tertiary
Minimal weight. For low-priority or frequently repeated actions in dense UIs.

Dos & Don'ts

Do

  • Use one Primary button per view to indicate the single most important action
  • Pair Neutral + Primary (or Neutral + Danger) for all confirm/cancel dialogs
  • Keep labels short, specific, and action-oriented - verb + noun where possible
  • Default to Medium size; use Large only for prominent hero CTAs, Small only for inline controls
  • Always show a confirmation dialog before any Danger Primary action executes
  • Use disabled + a tooltip that explains why the action is unavailable

Don't

  • Don't stack multiple Primary buttons on the same screen or modal
  • Don't use Danger buttons for non-destructive actions just to draw attention
  • Don't use vague labels like "OK", "Yes", or "Click here"
  • Don't mix sizes within the same button group (all must be the same height)
  • Don't silently disable a button without a clear explanation of why
  • Don't use a Link button as the primary action inside a form or dialog

Accessibility

WCAG 2.1 AA Checklist

Use native <button> elements - they provide keyboard focus, Space/Enter activation, and the correct ARIA role automatically.
Icon-only buttons must include aria-label="Action name" so screen readers can announce the button's purpose.
Use the native disabled attribute - it removes the element from tab order entirely. If you need the button focusable while inactive, use aria-disabled="true" instead and handle clicks in JS.
All button families meet WCAG AA contrast minimums: Primary (#1852fe text on #eef2ff bg) 4.7:1 · Danger (#dc2625 on #fef1f2) 5.1:1 · Neutral (#475569 on #fff) 5.9:1 · White on blue (#fff on #1852fe) 4.7:1.
Focus rings use :focus-visible so they appear only during keyboard navigation - not on mouse click. Never suppress outline without providing an equivalent visible focus indicator.
Minimum touch target is 40×40px - all sizes comply (Small = 32px height; wrap in a 40px tap area if needed for mobile contexts).
