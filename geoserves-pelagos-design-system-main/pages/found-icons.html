The Geoserve icon set is a custom library built for maritime operations software. Icons are available in line (outlined) and filled variants at 24×24px. All icons are delivered as optimised SVG and can be exported as PNG at any resolution.

Usage Guidelines

24×24px default
Designed on a 24×24 grid with 1.8px stroke width for pixel-perfect rendering.
Line for UI
Use the line variant in navigation, toolbars, and form controls.
Filled for emphasis
Use filled for active states, selected items, and high-emphasis CTAs.
Consistent colour
Inherit colour via currentColor - never hardcode icon colours.
Accessible labels
Pair icons with visible text or an aria-label for screen readers.
Maritime icons
Ship, fleet, wave, cargo, and port icons are reserved for maritime-specific contexts.

Variants

Line
Outlined strokes. Use for default/idle states in navigation, toolbars and lists.
Filled
Solid shapes. Use for active states, selected items, and high-emphasis actions.
