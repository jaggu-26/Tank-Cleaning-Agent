Usage Guidelines
📐 Sizing

Render illustrations between 160–480px. Never scale below 120px — fine details become unreadable. Maintain 1:1 aspect ratio at all times.

🎨 Colour

Do not recolour illustrations. They reference the Pelagos palette internally. Placing them on white or light-grey (--prim-grey-50) backgrounds works best.

📝 Accessibility

Always add a descriptive alt attribute. Use aria-hidden="true" if the adjacent heading already conveys the meaning.

💾 File format

Use SVG for web (scales perfectly, small file size). Use PNG at 2× (1600px) for documents, presentations, and email clients that can't render SVG.

In code
<!-- SVG via img tag -->
<img src="Assets/illustrations/img-sent.svg"
     alt="Confirmation that the message was sent"
     width="240" height="240" />

<!-- React component -->
import { ReactComponent as SentIllustration } from '@pelagos/illustrations/img-sent.svg';
<SentIllustration width={240} height={240} aria-label="Sent" />
