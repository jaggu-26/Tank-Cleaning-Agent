Design Tokens

Token Architecture

Three tiers keep values, meaning, and usage cleanly separated. Change a primitive and every semantic and component token updates automatically.

Tier 1
Primitive

Raw values - no semantic meaning. The single source of truth for every value in the system.

--prim-marine: #1852FE --prim-space-4: 16px --prim-radius-sm: 4px
Tier 2
Semantic

Purpose-driven aliases that reference primitives. Communicate intent, not appearance.

--color-brand → --prim-marine --space-md → --prim-space-4 --radius-sm → --prim-radius-sm
Tier 3
Component

Component-specific tokens that reference semantic tokens. Scoped, overridable per theme.

--btn-primary-bg → --color-brand --btn-radius → --radius-sm --btn-height-md: 40px
