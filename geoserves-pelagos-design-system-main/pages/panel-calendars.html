Calendar

Overview

The Calendar panel is a full-featured date-selection component. Date cells are pill-shaped (30px × 39px, border-radius 20px) matching the Figma specification. Clicking the month title switches to a month or year picker. Supports single-date, date-range, and date+time variants. Click any date or the month title to explore.

Anatomy

Five zones: navigation header (month title is clickable), weekday labels, a 7-column pill-cell day grid, and an optional footer. The date+time variant adds a dark header and a side time-picker panel.

  1. Header — Prev/Next buttons (circle 30px) + month-year title button. Title is a pill-shaped button; clicking switches to Month Picker view.
  2. Weekday labels — Mo–Su (Mon-first). --prim-font-size-xs / --prim-font-weight-semibold / colour #64748b.
  3. Today cell — Pill: 39×30px, border-radius: 20px, bg #dcebff, text #001e4c / bold.
  4. Selected cell — Pill: same dimensions, bg #1852fe, text #ffffff.
  5. Footer strip — Shows selected date, range, or date+time. Background --color-surface-subtle.

Semantic Pattern

The calendar uses role="application" with a live-updated aria-label. The day grid is role="grid". Each cell is role="gridcell" with aria-label (full date string), aria-selected, and aria-current="date" for today.

Overview

<Calendar> supports controlled (value+onChange) and uncontrolled (defaultValue). Pass mode="range" for range selection, showTime for date+time. Date cells use the Figma-spec 39×30px pill shape.

<gs-calendar> supports [(value)], [(range)], and [showTime]="true".

Usage Patterns
JSX
// Booking with date + time
function BookingForm() {
  const [dt, setDt] = useState<Dayjs>(dayjs());
  return (
    <Calendar
      value={dt}
      onChange={setDt}
      showTime={{ minuteStep: 15 }}
      disabledDate={(d) => d.isBefore(dayjs(), 'day')}
    />
  );
}

// Date picker (calendar in Popover)
function DatePickerField() {
  const [date, setDate] = useState<Dayjs|null>(null);
  const [open, setOpen] = useState(false);
  return (
    <Popover open={open}
      content={
        <Calendar
          value={date}
          onChange={(d) => { setDate(d); setOpen(false); }}
        />
      }
    >
      <TextField
        value={date?.format('DD MMM YYYY') ?? ''}
        placeholder="Select date"
        readOnly
        onClick={() => setOpen(!open)}
      />
    </Popover>
  );
}

Full Example
JSX
import { useState } from 'react';
import { Calendar } from '@pelagos/react-components';
import dayjs, { Dayjs } from 'dayjs';

export function AppointmentPicker() {
  const [dt, setDt] = useState<Dayjs>(dayjs());

  return (
    <div>
      <Calendar
        value={dt}
        onChange={setDt}
        showTime={{ minuteStep: 15, format: 'hh:mm A' }}
        disabledDate={(d) =>
          d.isBefore(dayjs(), 'day') ||
          d.day() === 0 || d.day() === 6  // no weekends
        }
      />
      <p>Selected: <strong>{dt.format('ddd, D MMM YYYY · hh:mm A')}</strong></p>
    </div>
  );
}

On This Page

When to Use
  • Date selection in forms — Booking, scheduling, filtering by date.
  • Date range for stays / projects — Check-in/check-out, sprint duration, leave periods. Use dual-calendar range variant.
  • Date + time scheduling — Appointments, meetings, event creation. Side time picker shows available slots.
  • Event calendars — Full-width with dateCellRender showing event indicators per day.
When Not to Use
  • Known exact date — A date text field is faster for birthdates or fixed past dates.
  • Month/year only — Use a Dropdown pair instead of a full calendar.
  • Time selection alone — Use a standalone Time Picker; the calendar+time combo is for when both are required.
Best Practices
  • Default to today's month — Always open on the current month with today highlighted.
  • Explain disabled dates — Add a helper note explaining availability constraints.
  • Close popover on selection — Dismiss the Popover as soon as the user selects a date.
  • Keep cell content minimal — One dot or a short label in dateCellRender; never overflow the pill.
Patterns
  • Date Picker — Calendar in a Popover, triggered by a Text Field. Close on selection.
  • Date Range Picker — Dual calendar in a Popover. Start on left, end on right. Show "→" separator.
  • Appointment Booking — Full date+time variant. Disable weekends and past dates. Side time panel shows available slots.
  • Sprint Calendar — Full-width with custom cell renders marking sprint days.
Anti-patterns
  • ❌ Silent disabled dates — Users can't tell why.
    ✅ Fix: Add tooltip or helper text explaining the constraint.
  • ❌ Overloading cells — Long strings overflow the 39px pill.
    ✅ Fix: Use a dot indicator only; show details on hover.
  • ❌ No today anchor — Users get lost navigating.
    ✅ Fix: Default to current month with today clearly highlighted.
