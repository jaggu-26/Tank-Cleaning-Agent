Slider

Overview

A Slider lets users select a value — or range of values — from a continuous or stepped scale by dragging a thumb along a track. Pelagos provides a Single variant (one thumb) and a Range variant (two thumbs, filled between them). Hover the thumb to see the value tooltip.

Anatomy

Single thumb slider. The range slider adds a second thumb and fills the segment between them.

  1. Track — 4 px height, pill-shaped, grey (#e2e8f0). Full width.
  2. Thumb — 16 px circle, brand blue (#1852fe), 2 px white border + shadow. Draggable.
  3. Fill — Portion of track left of (single) or between (range) the thumb(s). Brand blue.
  4. Tooltip — Value bubble above thumb, shown while dragging or on hover.
Variants

Single thumb for one value, Range for a min–max selection. Both support marks and step constraints.

Accessibility

Native <input type="range"> provides ARIA semantics automatically. Always add a visible or screen-reader label.

AttributeElementValue
aria-labelinput[range]Descriptive name (e.g. "Volume")

aria-disabledinput[range]"true" when disabled

Overview

Two exports: Slider (single thumb) and RangeSlider (dual thumb). Built on native <input type="range"> for accessibility. Fill and tooltip are overlaid absolutely.

Use .gs-slider wrapper with .gs-slider__input + .gs-slider__fill. Call gsSliderUpdate(input) on each oninput event to keep the fill in sync.

  <div class="gs-slider__track-wrap">

    <input type="range" class="gs-slider__input"

When to Use
  • Continuous value selection — volume, brightness, opacity, zoom level where precise keyboard entry is less important than quick adjustment.
  • Range filtering — price range, date range, vessel tonnage filter — use the Range variant.
  • Visual proportion — when the relative position matters as much as the exact value (e.g. "roughly 70% load").
When Not to Use
  • Precise numeric input — use a with type="number" instead.
  • Small discrete lists — fewer than 5 options → use .
  • Touch-only tables — small sliders are difficult to grab on mobile; consider a stepper instead.
