Spacing

Spacing defines the consistent gaps and distances between UI elements. It helps maintain visual rhythm, hierarchy, and balance across the interface. Use the predefined spacing scale to ensure alignment and consistency between layouts, components, and typography.

Usage Guidelines

Use spacing tokens for gaps between elements, not for padding inside components. See the Padding page for inset spacing.

✓ DO
Use gap: spacing-16 for card grids
✓ DO
Use margin-bottom: spacing-8 between form fields
✗ DON'T
Mix spacing tokens with raw pixel values like margin: 15px
