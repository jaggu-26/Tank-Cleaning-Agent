Slideout

Overview

Slideout panels (drawers) are surface-level containers that slide in from the edge of the viewport — typically the right side — to present contextual detail, forms, or secondary workflows without navigating away from the current page. Unlike modals, slideouts do not block the entire UI; they allow users to maintain spatial awareness of the page behind them.

Non-blocking

Content behind the drawer remains visible. Users stay oriented within the current context.

Edge-anchored

Always attached to the viewport edge. Right-side is the standard; left-side for navigation contexts.

Scrollable content

The content zone scrolls independently. Header and footer are sticky and never scroll out of view.

Task-focused

Best for detail views, edit forms, filters, and settings that relate directly to a selected item on the page.

Variants

Two drawer variants cover the full range of use cases. Choose based on whether the background task needs to stay interactive while the drawer is open.

Anatomy

Every slideout is built from three zones: Header, Content, and Footer (optional). The Header and Footer are position-sticky — they remain visible while the Content zone scrolls independently.

The drawer always renders Header → Content → Footer in that order. Header and Footer are position:sticky so they remain fixed while Content scrolls.

  1. Header: Drawer title + close ×. Fixed height (56px), never scrolls. Separated from Content by a 1px divider.
  2. Content: The scrollable work area — detail views, forms, filter panels. Gets overflow-y: auto automatically.
  3. Footer optional: Right-aligned action buttons. Omit the prop for read-only drawers. When present, primary action is always rightmost.
  4. Close ×: Dismisses the drawer. Always present in the header's trailing slot. Also closeable via Escape key or overlay click.
  5. Overlay: Semi-transparent backdrop (Overlay variant only). Clicking it closes the drawer.
Sizes

Drawer width is fixed and set at the time of invocation. Choose the smallest width that comfortably accommodates your content. Never use Large on viewports narrower than 768px.

Narrow 320px

Status panels, simple detail views, short filter sets.

Default std 400px

Edit forms, vessel/voyage detail, user profile, settings panels.

Wide 560px

Multi-section edit forms, document previews, complex filter panels.

Large 800px

Data review side-by-side, report generation, step-heavy flows. Use sparingly.

Rule: Drawer width must never exceed viewport width minus 48px. On mobile, the drawer always spans 100% of the viewport width regardless of the configured size prop.

Interaction Behaviour

Slideouts follow a consistent set of interaction rules regardless of variant or content type. These rules ensure predictable behaviour across all surfaces where drawers appear.

Esc Close

Pressing Escape always closes the drawer. If the user has unsaved changes, show a confirmation prompt before discarding.

Overlay click — close

Clicking the overlay backdrop closes the drawer (Overlay variant). Disable with maskClosable={false} when unsaved changes exist.

Close × button

Always present in the header trailing slot. Clicking it closes the drawer unconditionally. Label with aria-label="Close panel".

Focus trap

Keyboard focus is trapped inside the drawer while open. Tab and Shift+Tab cycle through interactive elements within the panel only. Focus moves to the first focusable element on open.

Scroll isolation

The page body scroll is locked while an Overlay drawer is open. Push and Inline drawers do not lock body scroll — the page content alongside remains scrollable.

One drawer at a time

Never stack drawers. If a secondary action needs confirmation, use a modal on top of the open drawer. Nesting drawers creates confusing layering and breaks the focus trap.

Unsaved changes guard

When the drawer contains an edit form with unsaved changes, intercept close attempts (Esc, overlay, × button) and show a confirmation modal: "Discard changes?" with Discard + Keep editing actions.

Focus return

On close, keyboard focus must return to the element that triggered the drawer open. Maintain a ref to the trigger and call .focus() after the exit animation completes.

Motion & Animation

Drawers use a horizontal slide from the edge combined with an opacity fade. The enter curve is a deceleration easing (fast start, soft land) and the exit is an acceleration easing (gentle start, fast exit). Both curves come from the Carbon Design System expressive motion vocabulary.

Accessibility

WCAG 2.1 AA Checklist

Use role="dialog" and aria-modal="true" on the drawer panel element. Link the title via aria-labelledby pointing to the header title element.
Focus trap — keyboard focus must stay inside the drawer while it is open. On open, move focus to the first interactive element (usually the first form field or the close button if content-only).
Escape key closes the drawer. The × button must have aria-label="Close panel". Both must work even when focus is inside a form field.
Focus return — on close, focus must return to the trigger element that opened the drawer. Store a ref to the trigger before opening and call .focus() after the exit animation finishes.
Background inert — mark the rest of the page with inert or aria-hidden="true" while the drawer is open so screen readers do not read the dimmed background content.
Contrast — all text inside the drawer must meet 4.5:1 contrast ratio (WCAG AA). Placeholder text is exempt but must meet 3:1 minimum.
Reduced motion — honour prefers-reduced-motion: reduce. Skip the translateX animation entirely; use a 150ms opacity-only fade as the fallback.
Screen reader announcement — use aria-live="polite" on a visually hidden element to announce "Panel opened: [title]" when the drawer enters. Some screen readers do not automatically announce role="dialog" on slide-in panels.
Scroll lock (Overlay only) — prevent body scroll via overflow: hidden while the overlay drawer is open. Restore on close and also on browser back-navigation.

Implementation

The GS Drawer wraps Ant Design's Drawer component, wiring design-system CSS tokens through a SCSS bridge. Two variants are supported: overlay (floats above content with a dark backdrop) and push (shifts layout with no mask). All token values resolve at runtime from :root CSS custom properties — no hard-coded hex values live in component files.

theme/gs-theme.js

JavaScript · Geoserve Theme 
/**
 * Geoserve UI theme config – injected via ConfigProvider.
 *
 * Token values are read from the design-system CSS custom properties
 * at runtime via getComputedStyle so any update to :root cascades
 * here automatically – no hard-coded hex values in this file.
 *
 * Token chain example:
 *   colorPrimary  ←  --prim-marine  ←  :root { --prim-marine: #1852FE }
 *
 * Wrap your app root (or the Drawer's nearest ancestor) with:
 *   <ConfigProvider theme={gsTheme}>...</ConfigProvider>
 */
const cssVar = (name) =>
  getComputedStyle(document.documentElement).getPropertyValue(name).trim();

const gsTheme = {
  token: {
    colorPrimary:  cssVar('--prim-marine'),       // → #1852FE
    colorError:    cssVar('--prim-red-500'),      // → #DC2625
    borderRadius:  4,                             // --prim-radius-sm
    fontFamily:    cssVar('--prim-font-primary'),  // Gilroy stack
    fontSize:      14,                            // --prim-font-size-md
  },
  components: {
    Drawer: {
      zIndexPopup:         1000,
      footerPaddingBlock:  16,
      footerPaddingInline: 24,
      headerPadding:       '16px 24px',
      bodyPadding:         '0',
      paddingLG:           24,
    },
  },
};

export default gsTheme;

Drawer/Drawer.jsx

TypeScript · React 
import React, { useRef, useEffect, useCallback } from 'react';
import { Drawer as AntDrawer, ConfigProvider } from 'antd';
import gsTheme from '../../theme/gs-theme';
import './Drawer.scss';

/** Props accepted by the GS Drawer wrapper. */
interface DrawerProps {
  open:       boolean;
  onClose:    () => void;
  title:      string;
  width?:     number | string;
  variant?:   'overlay' | 'push';
  footer?:    React.ReactNode;
  loading?:   boolean;
  children:   React.ReactNode;
}

/** FOCUSABLE_SELECTORS – elements that should receive keyboard focus. */
const FOCUSABLE = 'a[href],button:not([disabled]),input,select,textarea,[tabindex]:not([tabindex="-1"])';

const Drawer: React.FC<DrawerProps> = ({
  open,
  onClose,
  title,
  width    = 480,
  variant  = 'overlay',
  footer,
  loading  = false,
  children,
}) => {
  const drawerRef  = useRef<HTMLDivElement>(null);
  const triggerRef = useRef<HTMLElement>(null);
  const titleId    = `gs-drawer-title-${title.replace(/\s+/g, '-').toLowerCase()}`;

  // Capture the element that opened the drawer so focus returns on close.
  useEffect(() => {
    if (open) {
      triggerRef.current = document.activeElement as HTMLElement;
    } else {
      triggerRef.current?.focus();
    }
  }, [open]);

  // Move focus into the drawer when it opens.
  useEffect(() => {
    if (!open || !drawerRef.current) return;
    const first = drawerRef.current.querySelector<HTMLElement>(FOCUSABLE);
    first?.focus();
  }, [open]);

  // Trap tab/shift-tab focus within the drawer.
  const handleKeyDown = useCallback(
    (e: React.KeyboardEvent) => {
      if (!open || !drawerRef.current) return;
      if (e.key === 'Escape') { onClose(); return; }
      if (e.key !== 'Tab') return;

      const focusable = Array.from(
        drawerRef.current.querySelectorAll<HTMLElement>(FOCUSABLE)
      );
      if (!focusable.length) return;

      const first = focusable[0];
      const last  = focusable[focusable.length - 1];

      if (e.shiftKey && document.activeElement === first) {
        e.preventDefault();
        last.focus();
      } else if (!e.shiftKey && document.activeElement === last) {
        e.preventDefault();
        first.focus();
      }
    },
    [open, onClose]
  );

  return (
    <ConfigProvider theme={gsTheme}>
      <AntDrawer
        open={open}
        onClose={onClose}
        title={title}
        width={width}
        placement="right"
        mask={variant === 'overlay'}
        footer={footer}
        className={`gs-drawer gs-drawer--${variant}`}
        rootProps={{
          role:            'dialog',
          'aria-modal':    variant === 'overlay' ? 'true' : 'false',
          'aria-labelledby': titleId,
          onKeyDown:       handleKeyDown,
          ref:             drawerRef,
        }}
      >
        {/* ARIA live region for loading state */}
        <div role="status" aria-live="polite" style={{ position: 'absolute', width: 1, height: 1, overflow: 'hidden', clip: 'rect(0,0,0,0)' }}>
          {loading ? 'Loading content' : ''}
        </div>
        {children}
      </AntDrawer>
    </ConfigProvider>
  );
};

export default Drawer;

Multi-Panel (Stacked) Drawers

Pattern — primary drawer opens a child drawer

JSX · Stacked Drawer Pattern 
import React, { useState } from 'react';
import { ConfigProvider } from 'antd';
import gsTheme from '../../theme/gs-theme';
import Drawer from './Drawer';
import DrawerFooter from './DrawerFooter';

/**
 * MultiPanelExample – demonstrates stacked drawers.
 * The primary drawer (z-index 1000) renders a second child drawer
 * (z-index 1010) inside its body. Both share the same token system.
 *
 * Rules:
 *  – Only one level of nesting is recommended for usability.
 *  – The child drawer closes before the parent whenever possible.
 *  – Use unique aria-labelledby ids for each drawer level.
 */
const MultiPanelExample = () => {
  const [primaryOpen, setPrimaryOpen] = useState(false);
  const [detailOpen,  setDetailOpen]  = useState(false);

  return (
    <ConfigProvider theme={gsTheme}>
      {/* Trigger */}
      <button onClick={() => setPrimaryOpen(true)}>Open Primary Drawer</button>

      {/* Primary Drawer — z-index 1000 (from gsTheme) */}
      <Drawer
        open={primaryOpen}
        onClose={() => { setDetailOpen(false); setPrimaryOpen(false); }}
        title="Record Detail"
        width={480}
        variant="overlay"
        footer={
          <DrawerFooter
            onCancel={() => setPrimaryOpen(false)}
            onConfirm={() => setPrimaryOpen(false)}
          />
        }
      >
        <div style={{ padding: '24px' }}>
          <p>Primary drawer content here.</p>
          <button onClick={() => setDetailOpen(true)}>Open Detail Panel</button>
        </div>

        {/* Child Drawer — z-index 1010, narrower, no extra mask */}
        <ConfigProvider theme={{ ...gsTheme, components: { Drawer: { ...gsTheme.components?.Drawer, zIndexPopup: 1010 } } }}>
          <Drawer
            open={detailOpen}
            onClose={() => setDetailOpen(false)}
            title="Edit Detail"
            width={320}
            variant="overlay"
            footer={
              <DrawerFooter
                onCancel={() => setDetailOpen(false)}
                onConfirm={() => setDetailOpen(false)}
                confirmLabel="Save"
              />
            }
          >
            <div style={{ padding: '24px' }}>Child drawer content.</div>
          </Drawer>
        </ConfigProvider>
      </Drawer>
    </ConfigProvider>
  );
};

export default MultiPanelExample;

useFocusTrap hook

TypeScript · Custom Hook 
import { useRef, useEffect, RefObject } from 'react';

const FOCUSABLE_SELECTORS = [
  'a[href]',
  'button:not([disabled])',
  'input:not([disabled])',
  'select:not([disabled])',
  'textarea:not([disabled])',
  '[tabindex]:not([tabindex="-1"])',
].join(',');

/**
 * useFocusTrap
 *
 * Traps keyboard focus within `ref` while `isOpen` is true.
 * On open  → moves focus to the first focusable element.
 * Tab      → cycles forward through focusable elements, wraps at end.
 * Shift+Tab→ cycles backward, wraps at start.
 * Escape   → calls `onClose`.
 * On close → restores focus to the element that triggered the drawer.
 */
export function useFocusTrap(
  ref: RefObject<HTMLElement>,
  isOpen: boolean,
  onClose?: () => void
): void {
  const triggerRef = useRef<HTMLElement | null>(null);

  // Capture trigger element & restore focus on close
  useEffect(() => {
    if (isOpen) {
      triggerRef.current = document.activeElement as HTMLElement;
    } else {
      triggerRef.current?.focus();
    }
  }, [isOpen]);

  // Move focus to first element on open
  useEffect(() => {
    if (!isOpen || !ref.current) return;
    const first = ref.current.querySelector<HTMLElement>(FOCUSABLE_SELECTORS);
    first?.focus();
  }, [isOpen, ref]);

  // Trap tab + handle Escape
  useEffect(() => {
    if (!isOpen || !ref.current) return;

    const el = ref.current;

    const handleKeyDown = (e: KeyboardEvent) => {
      if (e.key === 'Escape') {
        e.preventDefault();
        onClose?.();
        return;
      }

      if (e.key !== 'Tab') return;

      const focusable = Array.from(
        el.querySelectorAll<HTMLElement>(FOCUSABLE_SELECTORS)
      ).filter(n => !n.closest('[aria-hidden="true"]'));

      if (!focusable.length) { e.preventDefault(); return; }

      const first = focusable[0];
      const last  = focusable[focusable.length - 1];

      if (e.shiftKey && document.activeElement === first) {
        e.preventDefault();
        last.focus();
      } else if (!e.shiftKey && document.activeElement === last) {
        e.preventDefault();
        first.focus();
      }
    };

    el.addEventListener('keydown', handleKeyDown);
    return () => el.removeEventListener('keydown', handleKeyDown);
  }, [isOpen, ref, onClose]);
}

The gs-drawer component is a standalone Angular component. Use variant="overlay" for focused tasks and variant="push" for contextual side panels. Keyboard dismissal (Escape) is handled by @HostListener.

drawer/drawer.component.ts

TypeScript · Angular
import {
  Component, Input, Output, EventEmitter, HostListener
} from '@angular/core';
import { CommonModule } from '@angular/common';

export type DrawerVariant = 'overlay' | 'push';
export type DrawerSize    = 'sm' | 'md' | 'lg';

@Component({
  selector: 'gs-drawer',
  standalone: true,
  imports: [CommonModule],
  templateUrl: './drawer.component.html',
  styleUrls: ['./drawer.component.scss'],
})
export class DrawerComponent {
  @Input() open     = false;
  @Input() title    = '';
  @Input() variant: DrawerVariant = 'overlay';
  @Input() size:    DrawerSize    = 'md';
  @Input() closable = true;
  @Output() closed = new EventEmitter<void>();

  @HostListener('keydown.escape')
  onEscape(): void { this.close(); }

  close(): void { if (this.closable && this.open) this.closed.emit(); }
}
