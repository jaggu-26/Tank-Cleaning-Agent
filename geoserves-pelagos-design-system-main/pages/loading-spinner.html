Spinner

Overview

The Spinner is a circular indeterminate progress indicator. Use it whenever a system action is in progress and the duration is unknown — data loading, form submission, route transitions. It is always animated and never used as a static icon.

Colour Variants

Three colour options. The track (::before, static) is always grey — #E2E8F0 for brand/muted, semi-white for dark surfaces. The arc (::after) is a solid 270° sweep at full opacity — no fade, matching the Figma spec.

Motion Spec

Two-layer CSS animation: the track (::before) is always static. Only the arc (::after) rotates at constant speed — no easing — signalling ongoing work with no definite end point.

Overview

Import Spinner from the GeoServe component library. Combine size and variant props to cover all use cases. No extra dependencies needed — the animation is pure CSS.

Add the gs-spinner CSS classes directly to any element or use the SpinnerComponent for Angular template integration. The CSS lives in styles.css.

Basic Usage
JSX
// Default (md, brand)
<Spinner label="Loading" />

// Large + white (for dark backgrounds)
<Spinner size="lg" variant="white" label="Loading" />

// Inline with visible label
<Spinner
  size="sm"
  label="Saving changes…"
  showLabel
/>

// Button loading state — preferred: use .gs-btn--loading class (no extra DOM)
<button className="gs-btn gs-btn-primary gs-btn-md gs-btn--loading" disabled>
  Saving…
</button>

// Alternative: explicit Spinner component inside button
<button className="gs-btn gs-btn-primary gs-btn-md" disabled>
  <Spinner size="sm" variant="white" label="Saving" />
  Saving…
</button>

Reduced Motion
CSS
/*
 * Architecture: ::before = static track, ::after = rotating arc.
 * Only ::after has animation-play-state — track never moves.
 */
@media (prefers-reduced-motion: reduce) {
  .gs-spinner::after {
    animation-duration: 2s;              /* slow rotation only    */
    animation-timing-function: steps(8, end); /* stepped, less dizzying */
  }
}
CSS
/* styles.css — architecture: ::before = static track, ::after = rotating arc */
@media (prefers-reduced-motion: reduce) {
  .gs-spinner::after {
    animation-duration: 2s;
    animation-timing-function: steps(8, end);
  }
}

On This Page

When to Use
  • Unknown duration — whenever a process has no predictable end time (API call, file upload, route transition), use a Spinner. Use a Progress Bar when percentage completion is available.
  • Background actions — form auto-save, live search, row-level operations like approvals or status changes that don't block the full page.
  • Initial data load — place a centred md or lg spinner in a card or panel while the first data fetch resolves. Replace with a Skeleton for heavier layout previews.
When Not to Use
  • Deterministic progress — if you can report percentage (file upload, multi-step wizard) use a Progress Bar instead.
  • Initial page paint — for first meaningful paint, prefer a Skeleton Loader so users see layout structure before data arrives.
  • Long-running operations (>10s) — combine a spinner with status text; users need feedback that the system hasn't frozen.
Accessibility
  • Always add role="status" on the spinner element so screen readers announce state changes.
  • Include a visible or visually-hidden aria-label (e.g. aria-label="Loading vessel data") describing what is loading.
  • When the spinner is inside a button, set aria-hidden="true" on the spinner itself — the button's accessible label (e.g. "Saving…") already conveys the state.
  • Honour prefers-reduced-motion — slow the animation to avoid triggering vestibular disorders.
Anti-patterns
  • ❌ Multiple spinners on the same screen — confusing and looks broken. Show one spinner per loading region. Use Skeletons for page-level parallel fetches.
    ✅ Fix: one spinner per card or one full-page overlay — never both simultaneously.
  • ❌ Spinner without feedback for >3s — users lose confidence.
    ✅ Fix: after 3 seconds add a status message ("Still loading…"); after 10s offer a retry action.
  • ❌ Using xl spinner inline — xl is for full-page overlays only.
    ✅ Fix: use sm inside buttons and table rows; md/lg for panels and cards.
