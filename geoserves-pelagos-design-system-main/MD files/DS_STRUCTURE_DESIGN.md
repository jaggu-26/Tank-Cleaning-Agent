# Design Tab Structure Contract

## Required Order

```text
Overview
Anatomy
Variants
States
Interactions
Accessibility
Responsive Behaviour
```

## Optional Sections

```text
Motion
Content Guidelines
Do / Don't
Best Practices
Loading States
Error States
```

## Rules
- Reusable cards only
- Fixed hierarchy
- Identical spacing
- Only content changes
- Omit irrelevant optional sections
