# Design System Page Specification

## Purpose
Defines the universal page shell and documentation layout structure.

## Global Page Layout

```text
Page
├── Header
├── Left Navigation
├── Main Content
│   ├── Component Hero
│   ├── Preview Section
│   ├── Tabs
│   └── Tab Content
└── Right TOC
```

## Required Tabs

```text
Design
Code
Usage
```

## Rules
- Fixed layout shell
- Reusable card structure
- Identical hierarchy across components
- Replace only component-specific content
- Do not invent new layouts
