# Design System Component Style Contract

## Purpose
Defines universal visual styling behaviour for all documentation pages.

## Styling Rules
- Reusable cards
- Consistent spacing rhythm
- Unified typography hierarchy
- Shared preview containers
- Shared grid structures
- Shared code block styling

## Token Usage
Use foundation tokens for:
- spacing
- typography
- color
- border
- elevation
- motion

## Responsive Behaviour
- Desktop: multi-column
- Tablet: condensed grids
- Mobile: single-column
