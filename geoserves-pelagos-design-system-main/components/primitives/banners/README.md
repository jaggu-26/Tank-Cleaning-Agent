# Banner

Inline contextual message strip.

```jsx
import { Banner } from '@pelagos/components/primitives/banners';

<Banner variant="success" title="Vessel updated" message="Port call saved successfully." onClose={dismiss} />
<Banner variant="danger" title="Sync failed" message="Could not connect to AIS feed." />
```
