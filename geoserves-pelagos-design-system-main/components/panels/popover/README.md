# Popover

Floating content panel anchored to a trigger.

```jsx
import { Popover } from '@pelagos/components/panels/popover';

<Popover placement="bottom" content={<FilterMenu />}>
  <Button variant="secondary" iconRight={<ChevronDown />}>Filters</Button>
</Popover>
```
